# Farmer-to-Doorstep

Farmer-to-Doorstep is a team web application designed to connect farmers directly with customers, helping reduce middlemen and improve access to fresh farm products.

## Features
- Product listing
- User interaction
- Simple ordering interface
- Agent module support

## Technologies Used
- HTML
- CSS
- JavaScript
